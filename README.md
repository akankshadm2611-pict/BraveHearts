# BraveHearts

## About
BraveHearts is a web-based project designed to help users manage and analyze crime investigation information through an interactive dashboard.

## Features
- Interactive crime map
- Case management
- Suspect information
- Evidence management
- Crime analysis
- Interactive dashboard

## Technologies Used
- HTML
- CSS/ Tailwind CSS
- JavaScript/ Typescript
- React
- Leaflet
- OpenstreetMap
- Rechart

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.

## Future Scope
- Chatbot for particular case officers
- Advanced crime heatmaps
- Real-time data integration

1. Install dependencies:
   `npm install`
2. Run the app:
   `npm run dev`
