# BraveHearts

## About
We are team Brave hearts creator of Crime justice website.
Crime Justice is a web-based project designed to help users manage and analyze crime investigation information through an interactive dashboard.

## Features
- Interactive crime map
- Case management
- Suspect information
- Evidence management
- Crime analysis
- Interactive dashboard

## Technologies Used
- HTML
- CSS/ Tailwind CSS
- JavaScript
- Typescript/ react
- Leaflet
- OpenstreetMap
- Vite
- Plugin-React
- Recharts
- jsPDF
- Express

## How to Run
1. Download or clone the repository.
2. Open the project folder in VS Code.
3. Open `index.html` in your browser.
